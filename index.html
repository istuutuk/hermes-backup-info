Hermes Backup

Personal backup utility operated by the owner of the GitHub account istuutuk. This is an independent personal utility, not an official Google or Nous Research service.

Purpose

The utility is being configured to create recovery archives of the owner's Hermes configuration and data on a server and store them in the owner's Google Drive. Routine backup transfers run on the server and do not require a Mac to remain online.

Google Drive access

The utility requests only the Google Drive drive.file permission: access to files it creates or that the user explicitly selects for it. It does not request Gmail, Calendar, or unrestricted Drive access.

Setup status

Drive authorization has been tested. Scheduled archive creation, encryption and retention are not yet enabled and will be configured only with the owner's approval.
